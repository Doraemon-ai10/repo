# RBX Insight — Roblox Account Inspector

Next.js dashboard for public Roblox account information by username.

Includes account profile, creation date, presence, friends, followers, following, groups, badges, username history, created experiences and favorites. Roblox does not expose a public endpoint for total playtime across all experiences, so the app never fabricates playtime.

## Run
npm install
npm run dev

## Vercel
Import this repository into Vercel and select the Next.js framework. No Roblox cookie or API key is required.
